# KSmelova Murals

Исследовательское и визуальное досье для муралов ЖК «Ганимед».

- Публичная страница: <https://vldsmelov.github.io/ksmelova-murals/>
- 5 тематических линий
- 45 концепций
- 135 вертикальных эскизов
- Размер каждого эскиза: 1138×2560 px
- Формат изображений: WebP

## Структура

- `index.html` — самостоятельная интерактивная страница и данные всех сценариев.
- `media/murals/` — изображения, сгруппированные по пяти темам.
- `PROMPT_STYLE.md` — единый визуальный регламент серии.
- `scripts/extract-murals.js` — извлечение сценариев из HTML.
- `scripts/normalize-mural.py` — приведение изображения к 1138×2560 и WebP.
- `scripts/validate-site.js` — проверка структуры страницы и всех медиассылок.
